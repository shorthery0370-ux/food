## 🍽️ 상세 매장 안내 & 웨이팅 공략 팁

### 1. 숙성도 노형본점 (흑돼지 구이)
- **지역**: 제주시 원노형로 41 (노형동, 공항 차량 10분)
- **전화**: 064-711-5212
- **특징**: 720~960시간 워터에이징 & 드라이에이징 교차 숙성. 전문 그릴러가 최상의 굽기로 서빙.
- **캐치테이블 공략**:
  - 오전 11:00 (런치), 오후 15:30 (디너) 캐치테이블 앱 원격 줄서기 오픈.
  - 오픈과 동시에 마감되므로 1~2분 전 앱 로그인 후 광클 등록 필수!

### 2. 맛나식당 (갈치조림)
- **지역**: 서귀포시 성산읍 동류암로 41 (성산일출봉 도보 8분)
- **전화**: 064-782-4771
- **특징**: 달큼하고 짭조름한 비법 양념과 무조림의 조화. 가성비 최고의 제주 갈치조림 명소.
- **현장 웨이팅 공략**:
  - 캐치테이블 미지원. 매일 아침 06:00부터 식당 앞 수기 예약 장부 오픈.
  - 원하는 식사 시간대(오전 8:30~오후 1:30)를 지정하여 기록 후 시간 맞춰 방문.

### 3. 가시아방국수 (고기국수 & 돔베고기)
- **지역**: 서귀포시 성산읍 섭지코지로 10 (섭지코지 입구)
- **전화**: 064-782-3300
- **특징**: 24시간 우려낸 깊은 사골 육수에 도톰한 수육. 비빔국수와 돔베고기 쌈 조합 강력 추천.
- **캐치테이블 공략**:
  - 방문 30~40분 전 캐치테이블 앱 원격 웨이팅 신청 권장.
  - 호출 후 5분 이내 미입장 시 자동 취소되므로 이동 소요 시간 고려 필수.

### 4. 명진전복 (전복돌솥밥)
- **지역**: 제주시 구좌읍 해맞이해안로 1282 (평대~세화 해안도로)
- **전화**: 064-782-9944
- **특징**: 전복 내장(게우)을 듬뿍 갈아 넣은 고소한 밥과 버터 전복구이, 서비스 고등어구이.
- **현장 대기 공략**:
  - 캐치테이블 앱 미지원. 매장 카운터에서 전화번호 및 선주문 메뉴 등록.
  - 바로 앞 바다 뷰 전용 대기실에서 대기하면 전화로 입장 안내.

### 5. 순옥이네명가 (전복물회 & 전복뚝배기)
- **지역**: 제주시 도공로 8 (도두일동, 공항 차량 7분)
- **전화**: 064-743-4813
- **특징**: 현직 해녀 출신 대표의 직송 해산물. 된장 베이스의 칼칼한 전복뚝배기와 살얼음 물회.

  - 렌터카 픽업 후 이동 시간(약 15분)과 타이밍이 알맞게 맞아떨어집니다.

## 🛠️ Tech Stack & 프로젝트 구조

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Motion

```bash
├── src/
│   ├── assets/images/       # 고화질 제주 한식 및 테마 이미지
│   ├── components/
│   │   ├── CatchTableBadge.tsx   # 캐치테이블 상태 뱃지
│   │   ├── FilterBar.tsx          # 지역 및 캐치테이블 필터
│   │   ├── GithubExportModal.tsx  # README & JSON 코드 내보내기 모달
│   │   ├── RestaurantCard.tsx     # 식당 요약 카드 컴포넌트
│   │   └── RestaurantModal.tsx    # 식당 상세 정보 & 메뉴 팝업
│   ├── data/
│   │   └── restaurants.ts         # 5개 맛집 데이터셋
│   ├── types.ts                   # TypeScript 인터페이스 정의
│   ├── App.tsx                    # 메인 레이아웃 및 뷰포트
│   ├── index.css                  # Tailwind CSS 글로벌 설정
│   └── main.tsx                   # React 진입점
├── index.html
├── metadata.json
├── package.json
└── README.md
```

## 🚀 로컬 실행 방법 (Local Getting Started)

```bash
# 1. 저장소 복제 (Clone repository)
git clone https://github.com/your-username/jeju-korean-food-guide.git

# 2. 프로젝트 디렉토리 이동
cd jeju-korean-food-guide

# 3. 의존성 패키지 설치
npm install

# 4. 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하여 인터랙티브 리스트를 확인하실 수 있습니다.

## 📦 깃허브 배포 (GitHub Pages / Vercel 배포)

```bash
# 프로덕션 빌드 생성
npm run build
```

- **Vercel / Netlify**: 저장소 연동 후 Build Command `npm run build`, Output Directory `dist` 지정 시 1분 내 배포 완료.
- **GitHub Pages**: `gh-pages` 패키지 또는 GitHub Actions 워크플로우를 활용하여 손쉽게 정적 배포 가능.
